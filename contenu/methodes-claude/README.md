# Méthodes de Claude (skills)

Copies de sauvegarde des « skills » enregistrés sur le compte Claude de Bene. Claude les relit automatiquement quand la tâche correspond ; ce dossier sert d'archive et de référence.

| Fichier | Quand Claude l'utilise |
|---|---|
| `monteur-reels-benfit.md` | Monter un Reel face caméra BEN&FIT (DA naturelle, sous-titres, miniature, caption) |
| `audit-profil-instagram.md` | Noter le profil Insta sur 100 et réécrire nom, bio, épinglés, highlights |
| `plan-contenu-hebdo.md` | Plan de contenu de la semaine (quoi poster, quel jour, quel format) |
| `analyse-viralite-niche.md` | Classer les Reels d'autres comptes (vues ÷ médiane) et réécrire les idées gagnantes |

⚠️ Modifier ces fichiers ne change pas les skills du compte : pour les mettre à jour, le demander à Claude (il propose la modification à enregistrer).
