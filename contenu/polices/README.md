# Polices BEN&FIT

- **Coda ExtraBold** : sous-titres (blanc, bords bleus) et textes du motion design.
- **Coda Regular** : textes secondaires.
- **Anton** : grands chiffres (« 4 », « 01 », chronos).
- **Instrument Serif** (Italic) : le serif italique des titres mixtes (« Les *séances* », « Carte *preuve* ») et des effets verre.
- **Permanent Marker** : annotations « feutre » du style v2 (légendes de polaroid, petites notes), avec parcimonie.
