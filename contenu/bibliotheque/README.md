# Bibliothèque BEN&FIT (GIFs, images, b-roll)

Réservoir d'illustrations réutilisables pour les Reels et les montages.

| Dossier | Contenu |
|---|---|
| `exercices/` | Schémas d'exercices (images fixes) |
| `sport/` | GIFs de mouvements : course, rameur, tractions, haltéro… |
| `reactions/` | GIFs drôles / réactions (let's go, confus, fatigué, content…) |

## Ajouter des fichiers
Sur github.com : ouvre le dossier → **Add file** → **Upload files** → glisse les fichiers → **Commit changes**.
Limite : 25 Mo par fichier depuis le site (100 Mo en ligne de commande).
Pour les vidéos plus lourdes (rushs 4K), utiliser une Release GitHub.

Nommage conseillé : `pilier_mouvement_angle.ext` en minuscules, sans accents ni espaces
(ex. `build_squat-lourd_profil.mp4`, `run_footing_pieds.mp4`, `move_squat-profond_profil.mp4`).

## Droits d'utilisation (à garder en tête)
- **Personnages de films/animés** (Vice-Versa, Pikachu, One Piece, Jujutsu Kaisen, Batman) : œuvres protégées, à éviter dans les Reels publiés par la marque.
- **Images `exercices/`** : portent le filigrane « Strength Level », à éviter en publication.
- Déjà utilisés dans le Reel « 4 qualités » : `let.s.go.gif`, `happy2.gif`, `confused.gif`, `jogging.gif`, `row.erg.gif`, `happyb.lift.gif`.
