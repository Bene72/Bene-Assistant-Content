# Le cerveau des D.A BEN&FIT

**À lire en premier par Claude avant toute création visuelle** (Reel, carrousel, miniature, animation 3D, affiche).
Une fiche par direction artistique. La charte commune ci-dessous s'applique partout, sauf mention contraire dans une fiche.

## Charte commune BEN&FIT

| Rôle | Valeur |
|---|---|
| Couleur principale | bleu marine `#0A206B` |
| Accent (la seule) | bleu vif `#2E6BFF` |
| Fond / texte clair | blanc `#FFFFFF` |
| Fond sombre (cartes de fin, miniature studio) | marine profond `#030A1A` |
| Bleu clair sur fond marine (texte secondaire, italique) | `#8CB8FF` |

- **Rester sur ces couleurs uniquement** : pas d'autres bleus, pas d'autres teintes (pas de jaune, pas de violet, pas de dégradé arc-en-ciel). L'orange cité au début pour les carrousels n'est plus utilisé, sauf si Bene le redemande.
- **Polices** (dans `contenu/polices/`) : **Coda** (sous-titres, textes, ExtraBold), **Anton** (titres, chiffres), **Permanent Marker** (annotations manuscrites, avec parcimonie), un **serif italique** pour les titres mixtes (« Les *séances* »).
- **Logo** : dans `contenu/logos/` (logo BEN&FIT en bas à droite des carrousels).
- **Piliers éditoriaux** : BUILD (force) · RUN (endurance) · PERFORM (performance) · MOVE (mobilité).
- **Ton** : tutoiement, direct, coach qui explique simplement.

## Règle d'or (toutes les DA)
Le rendu doit faire **« créateur humain », pas « IA »** : l'audience de Bene reconnaît les visuels générés et décroche.
- ✅ vraies images de Bene, effets sobres qui servent le propos, une seule couleur d'accent.
- ❌ look saturé, halos, lueurs, dégradés, éclairs/statues/fumée « épique » (« ça fait boomer qui découvre GPT »), pictogrammes vectoriels parfaits, tableaux de bord pleins de jauges, le même rebond sur chaque élément (« ado de 12 ans qui pousse les boutons »).
