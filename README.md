# Bene Assistant & Contenu BEN&FIT

Tout ce qui sert à l’assistant et à la création de contenu BEN&FIT, au même endroit.

| Dossier | Contenu |
|---|---|
| `agent-telegram/` | Agent Ben&Fit perso (bot Telegram + Claude). Voir son README. |
| `contenu/benfit-reels/` | Reels Instagram : `suivi-performances.md` (tableau de suivi), `design-system-v2.md` (style « naturel »), brief de post-production et `fabrique-montage/` (scripts du montage : transcription, coupes, étalonnage, sous-titres Coda, motion design, son). |
| `contenu/bibliotheque/` | GIFs, images et b-roll réutilisables (voir son README). |
| `contenu/polices/` | Polices Coda et Anton (sous-titres et titres des Reels). |
| `contenu/benfit-3d/` | Fabrique de clips d’athlète 3D BEN&FIT (scripts + exemple de l’arraché, référence de qualité). |

## Vidéos lourdes
- GIFs, images et petits clips (< 25 Mo) : directement dans `contenu/bibliotheque/`.
- Rushs 4K (souvent > 100 Mo) : Release GitHub « rushs » de ce dépôt (onglet « Releases » → glisser les fichiers).

## Charte BEN&FIT
- Couleurs : bleu marine `#0a206b`, blanc, bleu vif d’accent.
- Sous-titres : police **Coda** blanche, bords bleus, mots-clés dans un bloc bleu.
- Piliers éditoriaux : BUILD (force) · RUN (endurance) · PERFORM (performance) · MOVE (mobilité).
