# Bene Assistant & Contenu BEN&FIT

Tout ce qui sert à l’assistant et à la création de contenu BEN&FIT, au même endroit.

## 🚀 Démarrer une nouvelle conversation avec Claude
Une conversation par création (Reel, carrousel, miniature…). Il suffit d'écrire, par exemple :
- **Reel face caméra** : « Nouveau Reel BEN&FIT. Accroche : … Points : 1… 2… 3… Phrases à afficher : … Les rushs sont dans la Release « rushs » de Bene72/Bene-Assistant-Content. »
- **Reel d'entraînement** : « Monte le Reel d'entraînement avec le prompt `contenu/benfit-reels/prompt-reel-entrainement.md` » (+ logos et liste de ce qui a été filmé).
- **Carrousel** : « Fais un carrousel BEN&FIT style storytelling (ou briefing éditorial) sur … »
- **Plan / analyse** : « Fais mon plan de contenu de la semaine », « Audite mon profil Insta », « Analyse ces Reels concurrents » (+ captures).

Claude retrouve seul : la D.A dans `contenu/da/` (le cerveau des D.A), ses méthodes dans `contenu/methodes-claude/`, les scripts dans `contenu/benfit-reels/fabrique-montage/`.
Version visuelle en ligne des D.A : design system « BEN&FIT » sur claude.ai → https://claude.ai/artifact/Syt3nTXWrzmtGJaMoSY3hk

## Vidéos lourdes
- GIFs, images et petits clips (< 25 Mo) : directement dans `contenu/bibliotheque/`.
- Rushs 4K (souvent > 100 Mo) : Release GitHub « rushs » de ce dépôt (onglet « Releases » → glisser les fichiers).

## Charte BEN&FIT
- Couleurs : bleu marine `#0A206B`, blanc, bleu vif `#2E6BFF` (et rien d'autre). Détails : `contenu/da/README.md`.
- Sous-titres : police **Coda** blanche, bords bleus, mots-clés dans un bloc bleu.
- Piliers éditoriaux : BUILD (force) · RUN (endurance) · PERFORM (performance) · MOVE (mobilité).
